# 周天 zhoutian

平衡三进制格网 ×《周易》结构 —— 单页交互演示，三台顶部切换。

**▶ https://rjialondon.github.io/jisi/**

**太极台**(双盘正交·双机位) · **周天台**(729 格状态空间) · **卦台**(先天游龙·拆半盘)

指尖拖动旋转 · 双指捏合缩放 · 左下机位仪表实时读数 · 右上 ☰ 控制台

### 2026-09-05 · 三台交互修订

- 桌面仍在顶部切台；窄屏切台条移到底部，给仪表和缩放留出位置。
- 三台共用单指／鼠标旋转、双指捏合和滚轮缩放；抬起一指后，余下一指可继续旋转。
- 自转与太极引擎按经过的秒数计速；视角锁定且引擎关闭时停绘，操作后重绘。页面隐藏时暂停，返回时不追补离开的时间。
- 卦台「乾坤大挪移」再次点击，恢复操作前的鱼身、机位、世界姿态、自转开关和余速。
- 「全台复位」恢复本台初始机位、图层和自转；太极台同时恢复鱼身相位、关闭引擎和圆化，卦台同时撤销镜像并恢复基准盘。
- 「圆化」仅在机位1且视角锁定时可开启，是整幅画面的纵向拉伸显示。画面常驻提示其非原始比例；手动转向、切换机位或开启自转时自动关闭。图形本身和卦位映射未因本次交互修订改变。
- 切台统一撤除监听、取消待绘帧，逐项释放共享几何、材质、纹理，再释放绘图上下文。

本轮只修订显示与交互；既有古籍解释和几何映射的成立范围不由这些测试扩大。

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

本机已有 Chrome 时可用 `PLAYWRIGHT_CHANNEL=chrome npm run test:browser`。
计时、行止、手势中断、资源释放由单元测试验证；浏览器测试覆盖三台操作、真实双指输入、大挪移撤销、圆化退出、引擎启停、窄屏布局与反复切台。
触屏测试使用 Chromium 的触摸输入模拟；不等于已经在实体 iPhone／Android 上测试。

## 部署

推送到 `main` 分支即自动构建部署(`.github/workflows/deploy.yml`:npm ci → vite build → Pages)。
仓库 Settings → Pages → Source 选 **GitHub Actions**,一次设置,永久生效。

`vite.config.js` 中 `base: "./"` 用相对路径,故仓名任改,无须动配置。

## 标准机位

| 台 | 机位 | 读数(地·天·人) | 所见 |
|---|---|---|---|
| 太极台 | 显影(合) | +0.707 · +0.707 · 0.000 | 双盘同椭圆,旋转恒满太极 |
| 太极台 | 分体(离) | +0.577 · +0.577 · −0.577 | 三轴等距 120°,两鱼永不相触 |
| 卦台 | 体对角望 | ±0.577 三连 | 八角摊正六边形+两卦叠心 |
| 卦台 | 常态任意位 | 非退化任意 | 九宫(八点围一心,对宫对径) |

太极台标准相位:阴鱼正转 90°(自地+端看向原点),阳鱼守初始,人层隐。
